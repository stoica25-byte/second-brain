# Implementation Plan: Visual Second Brain & AI Memory Dashboard

This plan outlines the architecture, features, and steps to build a local **Second Brain** system. It allows you and the AI (me) to record ideas, journal logs, skills, resources, and errors & solutions using Obsidian-compatible Markdown files. It features a premium, interactive web dashboard featuring a 2D force-directed node graph to visualize connections, edit/create notes, curate incoming sources, search your vault, and sync changes to GitHub.

---

## User Review Required

> [!IMPORTANT]
> **Git & GitHub Synchronization**:
> We have designed a hybrid Git Sync system. To back up your vault and keep it synced across multiple devices without terminal usage:
> 1. The server will run `git pull --rebase` automatically on startup to ensure your local brain is up to date.
> 2. The dashboard header will feature a glowing **"Sync Vault"** button to stage, auto-commit, pull, resolve, and push your changes.
> 3. If conflicts arise, the backend automatically creates a conflict duplicate file (e.g. `MyNote (Sync Conflict 2026-06-02).md`) and shows a conflict resolution prompt in the UI, ensuring no data is ever lost.
> *Please verify that you have a GitHub repository URL ready to link (or we can initialize a local Git repository first and you can link it later via Settings).*

> [!NOTE]
> **MCP & External Ingestion (e.g., NotebookLM)**:
> To keep your active ideas separate from raw external data (maintaining "cognitive hygiene"), we will save ingested MCP files inside a dedicated folder `vault/sources/` (colored **Gold** in the graph).
> - New files enter the **"Inbox"** (unread state).
> - You can read, link them, or click **"Promote to Idea" / "Promote to Skill"** to move the file and change its node color instantly.
> - The ingestion endpoint (`POST /api/ingest`) is protected by an `X-Ingest-Token` header to prevent CSRF spam.

### [Component 2] Python Backend (FastAPI)

Exposes REST APIs to the frontend and local integrations. Bound strictly to `127.0.0.1` for network safety.

#### [NEW] [backend/main.py](file:///c:/Users/Estudiante/Downloads/seond-brain/backend/main.py)
Implements:
- **Directory Watcher & Indexer**: Recursively scans the vault, compiles YAML frontmatter metadata, parses wikilinks (handling aliases case-insensitively), and compiles/saves `vault/brain_index.json`.
- **Path Traversal Protection**: Inspects all file requests to ensure they resolve within the `vault/` directory boundary, blocking `../` traversal.
- **Write Lock (`asyncio.Lock`)**: Prevents file corruption during concurrent edits.
- **Git Sync API**:
  - `GET /api/git/status`: Checks if there are uncommitted changes or remote commits to pull.
  - `POST /api/git/sync`: Stages files, commits locally (`"Brain Sync: [AI/User] Edits"`), pulls from the remote with `--rebase`, creates duplicate files for conflicts, resolves to a clean state, and pushes to GitHub.
- **Ingestion API (`POST /api/ingest`)**:
  - Accepts external notes (from NotebookLM, Drive, Notion, Browser).
  - Sanitizes the title for filename safety and saves it inside `vault/sources/`.
  - Scans content for existing note titles. If a match is found (e.g. "FastAPI"), it appends `[[FastAPI]]` to create automatic connections.
  - Enforces `X-Ingest-Token` validation (token stored in `.env`).
