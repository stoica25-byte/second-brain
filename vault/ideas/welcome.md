# Welcome to Your Second Brain!

This is the central hub of your personal visual knowledge base. Every circle in the graph is a node representing a file in your `vault/` directory.

## What is this?
A secure, offline-first dashboard served locally that helps you track your notes, ideas, learnings, daily logs, and AI memory.

## Note Categories
Your brain is divided into five color-coded categories:
- <span style="color:#BB9AF7">**Ideas** (Lavender)</span>: Projects, drafts, brainstorming, design documents (like this note!).
- <span style="color:#73DACA">**Skills** (Neon Teal)</span>: Guides, code snippets, syntax templates, and workflows. Try checking [[Skill: Agent Debate Protocol]] to see how my subagent system resolves debates!
- <span style="color:#F7768E">**Errors & Solutions** (Coral Red)</span>: Bug logs, stack traces, fixes, and lessons learned. Check [[Error: Python PATH Execution Bug]] to see an example error log!
- <span style="color:#7AA2F7">**Journal** (Ice Blue)</span>: Daily work logs, achievements, and notes.
- <span style="color:#E0AF68">**Sources** (Amber Gold)</span>: Clippings, reports, and data imported from external sources like NotebookLM or Google Drive. New sources appear in your **Inbox**.

## How to Connect Notes
Simply type Obsidian-style wiki-links `[[Name of Note]]` in the editor to link notes. The backend automatically reads them and draws connection lines on the graph canvas.
